# 🌤️ SkyCast — Weather Forecast Web App

SkyCast is a responsive weather forecast web application that allows users to search for a city and view its current weather information through a simple and intuitive interface.

🔗 **Live Demo:** https://viveknahar17.github.io/SkyCast/

## ✨ Features

* 🌍 Search weather by city
* 🌡️ Display current temperature and weather conditions
* 💧 View humidity information
* 💨 View wind information
* 🔄 Fetch real-time weather data from a weather API
* 📱 Responsive design for desktop and mobile devices
* ⚠️ Handles invalid city searches and API errors
* 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** — Application structure
* **CSS3** — Styling and responsive layout
* **JavaScript** — Application logic and API integration
* **Weather API** — Fetching real-time weather data
* **GitHub Pages** — Deployment

## ⚙️ How It Works

1. The user enters the name of a city.
2. JavaScript sends a request to the weather API.
3. The API returns the weather data in JSON format.
4. JavaScript processes the response.
5. The application dynamically updates the interface with the weather information.

```text
User Input
    ↓
JavaScript
    ↓
Weather API
    ↓
JSON Response
    ↓
DOM Update
    ↓
Weather Information
```
